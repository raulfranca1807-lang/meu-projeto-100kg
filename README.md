# Projeto 80 KG
Aplicativo pessoal de acompanhamento nutricional, peso e registro de aplicações.

Meta calórica configurada: 1.800 kcal/dia. Três refeições diárias. Peso inicial de referência: 110 kg; meta: 80 kg.

Os dados são armazenados localmente no navegador. Use a opção Exportar backup para salvar uma cópia.
