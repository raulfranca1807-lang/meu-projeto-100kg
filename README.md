# Projeto 80 KG
Aplicativo pessoal de acompanhamento nutricional, peso e registro de aplicações.

Meta calórica estimada: aproximadamente 2.070 kcal/dia. Plano com quatro refeições: café da manhã com 3 ovos, 40 g de aveia, leite desnatado para o mingau e canela; três refeições com 150 g de frango cozido, 200 g de arroz integral cozido e 100 g de legumes; no jantar, acrescentar 150 g de abacaxi.

As estimativas consideram 100 ml de leite no mingau, embora a quantidade usada possa variar, e não incluem óleo extra no preparo. Os valores variam conforme alimentos, marcas e preparo. O aplicativo registra dados localmente no navegador; use Exportar backup para guardar uma cópia.
