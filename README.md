# Projeto 80 KG
Aplicativo pessoal de acompanhamento nutricional, peso e registro de aplicações.

Meta diária: 1.800 kcal. Cardápio com 3 refeições, baseado no plano alimentar enviado pelo usuário e com porções ajustadas proporcionalmente. Peso inicial de referência: 110 kg; meta: 80 kg.

Os registros são salvos localmente no navegador. Use Exportar backup para salvar uma cópia.
